### Изменения в v1.9.7:

- **Первый выпуск форка nfqws2-android-ext**: свой id модуля, настройки общие с оригиналом (`/data/adb/nfqws2`), при установке оригинальный модуль отключается
- **DNS по профилям** (Настройки → Инструменты): свои DoH, DoH3, DoT, DoQ, обычные DNS и DNS-штампы для выбранных доменов, остальное — через DNS сети или любой профиль. До 32 профилей, пресеты XBox DNS, Comss.one и GeoHide, режим «Без службы обхода», проверка домена, выбор и удаление нескольких профилей долгим нажатием, отдельный журнал DNS; профили входят в резервную копию
- Домашняя Wi‑Fi: пауза больше не залипает на мобильной сети после быстрого переподключения Wi‑Fi или перезагрузки — домашней считается только Wi‑Fi, через которую реально идёт трафик, а после смены сети состояние перепроверяется
- Главный экран: кнопка «Вернуть паузу» после ручного запуска дома; убраны «Очередь», «Потери» и лимит connmark; в extended видно, включён ли DNS
- Резервные копии — в папке `Download/nfqws2`; исправлены ошибка «Argument list too long» при создании копии и восстановление больших архивов из файла
- Исправлено: правило фильтра по приложениям могло получить лишнюю запятую перед UID
- Исправлено: из версии и названий стратегий в WebUI пропадали дефисы
- WebUI: сохраняется прокрутка при возврате назад; лист выбора стратегии с размытием фона и закрытием смахиванием вниз; текст выделяется только в полях ввода и журналах; аккуратнее волна нажатия на чипах
- Убраны флаг WAKELOCK и лишняя строка про conntrack в журнале при каждом запуске

### Изменения в v1.9.5:

- Поддержка раздачи интернета (Wi-Fi Hotspot, USB-модем, Bluetooth): перехват транзитного трафика в цепочке FORWARD mangle (nfqws_fwd), защита от утечек и блокировка QUIC

- Привязка и кэширование стратегий по сетям (NET_STRATEGY): автоматическое запоминание выбранной стратегии отдельно для каждой Wi-Fi сети (по SSID) и мобильного оператора

- Твик net.ipv4.tcp_timestamps = 1 для корректной работы десинхронизации/сплиттинга без сброса сессий ТСПУ
- Новые CLI-команды: current-network, list-net-strategies, clear-net-strategies
