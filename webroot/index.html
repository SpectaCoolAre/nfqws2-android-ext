Импорт конфигов nfqws2-keenetic

Файлы .txt, .conf, .bat, .ini или вставленный текст. Можно выбрать несколько файлов сразу.
В сетях из списка обход ставится на паузу и сам возобновляется, когда телефон из них уходит. Запустить службу вручную можно в любой момент — до смены сети она останется включённой.

Домашние сети

Сам подбирает обход для каждого сайта из блоков авторских стратегий и альтов Flowseal, запоминает удачный вариант за сайтом и помнит выученное отдельно для Wi‑Fi и мобильной сети. Без связи не перебирает ничего.
Как в Keenetic: запросы к доменам профиля и их поддоменам идут на его DNS-серверы (DoH, DoT, DoQ или обычные), остальные — на DNS по умолчанию. Работает независимо от службы обхода: остановка или пауза его не выключают.

Профили

Блокировка DNS

Файл hosts подменяется сразу, без перезагрузки и отдельного модуля. Он собирается из двух частей: обход ограничений и блокировка рекламы. Выключение возвращает системный hosts.

Обход ограничений

Записи «IP домен» для доступа к сервисам. Пресет загружается целиком и заменяет записи: для одного домена работает только одна запись.

Блокировка рекламы

Собирается из выбранных источников и своих доменов, кроме исключений. Список большой, поэтому открывается только файлом.

Источники

DNS-серверы

Запросы распределяются между серверами профиля; если ни один не ответил — уходят на DNS сети.

Стратегия обхода

  
Выбранная стратегия заменит nfqws2.conf, прежний сохранится как .bak. Ваши переключатели, режим списков и фильтр приложений сохранятся.

  
Удерживайте стратегию, чтобы изменить её, поделиться или скопировать
